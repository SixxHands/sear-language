# Sear

**Sear is an upcoming domain-specific language for infrastructure and factory management. Currently in private alpha.**

Sear is machine interface language for factory and infrastructure components. Sear is a language to act as a governing program in some cases, but in most cases is better suited for handling specific events, environments to avoid lack of oversight in large complexes. It is a great alternative to languages that hard code values and states on to mechanical components when often emergencies cannot rely on the function or precision of component states.
